# Earmatch 0.1.0

The first release of Earmatch, a beatmatching-by-ear overlay for rekordbox 7.

- **BPM precision**: covers the last decimal, both decimals or the whole BPM in each jog centre.
- **Waveform**: Split shows each deck in its own half with its own centred playhead; Hide Both blacks out the waveforms.
- **Phase meter**: CDJ-3000, CDJ-2000NXS2 and CDJ-2000NXS / XDJ-1000 styles, with a bar counter or a countdown to the next cue.
- **Booth presets**, **blind mode** and a **mix trainer** with a replay of the last transition.
- 2Deck and 4Deck layouts, horizontal and vertical.
- A window with four panes, **Live**, **Overlay**, **Practice** and **Setup** (⌘1–⌘4), that fits on screen without scrolling.
- English and Spanish, with a **Language** picker in Setup (System, English, Español) that switches the window and menus at once.
- Requires macOS 14 or later, on Apple silicon or Intel. Signed with Developer ID and notarized by Apple.
- Automatic updates: each time you open Earmatch it checks for a new version and asks whether to install it. It never takes the focus from rekordbox: an update found while rekordbox is in front, or by the daily check while Earmatch runs, shows up as **Update Available…** in the menus. **Check for Updates…** is in the menu bar menu, the app menu and Setup.
